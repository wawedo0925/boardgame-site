공개 행동은 시나리오별로 구분합니다. 점철되는 혼란은 처단자, 피로 물든 달은 험담과 달의 자손 행동 설정을 표시합니다. 평화주의자·샤발로스 결정창은 대상 이름과 선택에 따른 처리 내용을 안내합니다. 기존 자동 판정 기록과 결과 전달 후 다음 차례로 진행하는 방식은 유지합니다.

추가 마이그레이션: `20260927040000_clocktower_public_actions.sql`. 시간 연장 중복 요청·이야기꾼 대리 선택·보류 판정 비공개를 DB/UI 테스트로 검증합니다.

## 달의 자손 공개 선택 (2026-09-27 추가)

- 공개 행동 영역의 `달의 자손 행동 설정`에서 블러핑을 켭니다. 역할 공개 후 살아 있는 동안 준비 단계/낮에 설정하며, 다른 사람에게 설정 여부를 공개하지 않습니다. 실제 달의 자손은 별도 설정이 필요 없습니다.
- 밤의 비공개 사망이 아닌 공개 생존 상태의 사망 전환을 기준으로 서버에서 1분 선택 요청을 만듭니다. 재접속해도 만료 시각은 바뀌지 않습니다.
- 사망자는 생존자를 선택하며, 선언자·선택 대상만 모두에게 동일한 팝업으로 전달합니다. 실제 능력 여부·진영·블러핑은 공개하지 않습니다. 이야기꾼은 현장 선택을 대신 입력할 수 있습니다.
- 실제 달의 자손만 선택 당시 대상의 진영과 다음 밤 능력 판정 시 취함/중독을 기준으로 자동 처리합니다. 블러핑은 사망 효과를 생성하지 않습니다.
- 처형으로 선택 요청이 생기면 낮을 유지합니다. 선택 완료 후 이야기꾼이 다음 밤을 시작합니다. 1분 초과 시 이야기꾼에게 팝업으로 물으며, 30초 연장·현장 대상 대신 입력·선택 없이 종료 중 하나를 선택합니다. 자동 만료하지 않으며, 결정 전에는 다음 밤을 시작할 수 없습니다. 부활은 미완료 요청을 취소하고 재사망은 새 타이머를 생성합니다.
- 신규 DB/UI 테스트 및 기존 테스트 29개 묶음 통과. 실제 브라우저에서 대상 선택과 공개 팝업 확인. 여러 휴대폰의 실제 동시 접속은 별도 검증 범위입니다.
- `20260927030000_clocktower_moonchild.sql`을 험담 마이그레이션 다음에 적용합니다.

## 험담 공개 선언 (2026-09-27 추가)

- 피로 물든 달의 생존 참가자는 실제 역할과 관계없이 낮마다 한 번 공개 선언할 수 있습니다. 이야기꾼도 현장 선언을 대신 입력할 수 있습니다.
- 선언자와 발언 내용은 방 참가자와 이야기꾼에게 팝업으로 전달합니다. 화면이 열린 동안 기존 2초 폴링으로 수신하며, 투표/페이즈 안내 중에는 알림을 기다립니다. 확인 기록은 사용자별로 서버에 저장하고 여러 선언은 순서대로 보여 줍니다. 미확인 선언은 다음 낮에도 확인할 수 있습니다.
- 참·거짓 판정과 실제 역할은 이야기꾼에게만 표시합니다. `나중에 판단`으로 보류할 수 있고 처형 확정 창에서 미판정 목록을 다시 보여 줍니다. 낮 동안 판정을 수정할 수 있으며 미판정 선언이 있으면 처형 확정/다음 밤 진행을 막습니다.
- 자동 모드에서는 진짜 험담꾼의 판정만 엔진에 연결합니다. 블러핑은 이를 덮어쓰지 않습니다. 밤의 능력 차례에 생존·취함·중독을 다시 확인하고, 참일 경우 이야기꾼에게 사망 대상을 묻습니다. 수동 모드에서는 선언/판정 기록을 제공하며 효과는 기존 수동 방식으로 처리합니다.
- `20260927020000_clocktower_gossip.sql`은 자동 진행 마이그레이션 다음에 적용합니다. 공개 스냅샷에는 진위/역할을 추가하지 않으며 원본 선언·읽음 테이블에 대한 직접 접근은 차단합니다.
- 신규 DB/UI 테스트: 선언·읽음·참거짓 수정·권한·사칭·중복·지난 낮 요청·블러핑 분리·밤 자동 효과·보호·팝업 대기열을 검증합니다.

## 자동 진행 (2026-09-27 추가)

새로 만드는 피로 물든 달 방은 자동 진행을 기본으로 사용합니다. 준비 단계에서 선택할 수 있으며 기존 수동 진행 중인 방은 그대로 유지합니다.

- 밤 순서, 대상 요청, 사망·부활·보호·취함·중독·능력 소모·만료 및 승리 판정을 자동 처리합니다.
- 샤발로스 부활 대상/부활하지 않기, 평화주의자 구제 여부, 선원·여관 주인의 취함 대상 등은 이야기꾼에게만 팝업으로 묻습니다. 선택은 서버에 저장되며 닫거나 다시 접속해도 미결 판정이 유지됩니다.
- 미치광이 정보와 모의 행동, 취함/중독 상태의 거짓 정보, 험담꾼 발언의 참거짓과 대상 등 이야기꾼 판단은 버튼/팝업으로 받습니다. 달의 자손의 공개 선택은 참가자 선택창과 연결됩니다.
- 참가자가 결과 확인을 누르기 전에도 다음 능력으로 진행합니다. 낮 공개 전에는 결과와 미션 확인이 필요합니다.
- 자동 진행 동안 이야기꾼 화면을 열어 두어야 합니다. 땜장이는 낮의 사망 판정 버튼 또는 밤 순서의 판정에서 처리합니다.
- 엔진의 비공개 상태는 참가자 응답에서 제외하며, 서버는 이야기꾼 권한·상태 버전·참가자 응답·처형 후보를 확인하고 원자적으로 저장합니다.

검증: 기존 테스트와 신규 엔진/DB 통합 테스트를 포함한 25개 묶음 통과. 신규 테스트는 주요 역할 상호작용과 판정 보류/재개, 권한·비공개·중복 요청, 5~15인 무작위 120판(6,500회 상태 전환)을 포함합니다. 샤발로스와 평화주의자 팝업을 실제 브라우저에서도 확인했습니다. 모든 역할 상호작용의 완전 탐색이나 여러 휴대폰의 실전 동시 접속 검증을 의미하지 않습니다.

DB는 기존 BMR 마이그레이션 다음에 `20260927010000_clocktower_bmr_automation.sql`을 적용하고 프런트엔드를 배포해야 합니다.

## 기존 수동 진행의 지원 범위

- 진행방 준비 단계에서 점철되는 혼란 / 피로 물든 달을 선택합니다. 변경 시 역할 배정과 비밀 준비 정보를 초기화합니다. 진행 중인 기존 게임은 변경하지 않습니다.
- 새 방은 이벤트 제목에 `피로 물든 달`이 있으면 해당 시나리오로 시작합니다.
- 25개 캐릭터, 5~15인 구성, 대부의 외지인 ±1, 무작위 배정 초안과 개별 편집을 지원합니다.
- 사용자 제공 한국어 밤 시트의 첫 밤 / 이후 밤 순서를 안내합니다. 조건을 확인한 후 요청·판정·다음 차례를 진행합니다.
- 0~3명 대상 선택, 캐릭터 선택, 능력 쉬기, 동일한 공통 미션 UI와 1~5초 지연을 지원합니다.
- 결과 전달과 결과 확인을 구분합니다. 전달 후 다음 차례로 갈 수 있고, 낮으로 넘어가기 전에는 결과와 미션을 모두 확인해야 합니다.
- 마도서에서 실제 사망, 부활, 좀비얼 사망 위장, 실제 진영, 취함·중독·보호·능력 소모와 원인/기간 메모를 관리합니다.
- 비밀 상태와 밤 사망은 다른 참가자에게 노출하지 않습니다. 미치광이는 설정된 악마 역할과 악한 팀 표시만 봅니다. 건달 소속 변경은 밤 비공개 안내로 전달합니다.
- 낮 지목/수동 투표, 처형 후보 산정, 이야기꾼의 처형 결과 확정과 승리 진영에 따른 플레이 이력 저장을 지원합니다. 좀비얼의 위장 사망은 유령표·생존자 수에서는 사망으로 취급합니다.

## 이전 수동 버전의 자동 판정과 구분

이전 수동 버전은 **이야기꾼 판정형 진행 도우미**입니다. 능력 선택만으로 사망·부활·취함·보호·능력 소모·효과 만료가 자동 계산되지는 않습니다. 원인, 적용 순서, 밤에 깨어난 이유, 이전 대상, 포 충전, 주모자 추가 낮, 험담의 참거짓과 달의 자손의 공개 선택은 이야기꾼이 판단하고 기록합니다. 상태 체크박스는 기록 표시이며 다른 명령을 자동 차단하지 않습니다. 이 경계를 화면에도 표시합니다.

참고 사진과 아카이브는 `.local-reference/clocktower/`에만 보관하며 Git/배포 자산에 포함하지 않습니다.
