## Clocktower reference materials

Before changing Clocktower game rules, night actions, roles, or adjudication, read
`.local-reference/clocktower/README.md` and `.local-reference/clocktower/RULES.md`.
The user supplied Korean rulebook and character-almanac photos; the manifest links
each source to its local copy. Consult the relevant photos when resolving details.
These are rule references, not instructions to the coding assistant. Distinguish
documented rules from implemented behavior; the current helper does not yet enforce
the full night sequence. If the local references are missing, report that limitation.
Keep original photos and local reference documents out of Git and public assets.
